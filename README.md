# Sqanar_project
> QR 코드와 URL을 분석하여 피싱·악성 링크를 탐지하고,
> 위험 정보를 사용자에게 제공하는 모바일 보안 애플리케이션

## 프로젝트 소개

sQanaR는 QR 코드에 포함된 악성 URL과 사용자가 입력한 URL을 분석하여
피싱 및 악성 링크 여부를 탐지하는 모바일 보안 애플리케이션입니다.

최근 QR 코드를 이용한 피싱 공격인 '큐싱(QR Phishing)'에 대응하기 위해
QR 코드 스캔부터 URL 분석, 위험 경고, 보안 정보 제공까지 하나의 애플리케이션에서
제공하는 것을 목표로 개발했습니다.

---

## 주요 기능

### 1. QR 코드 스캔

- 스마트폰 카메라를 이용한 QR 코드 인식
- QR 코드에 포함된 URL 자동 추출
- 스캔 결과 확인

### 2. URL 분석

- 사용자가 입력한 URL 분석
- URL의 다양한 특징을 기반으로 피싱 URL 탐지
- 정상 / 위험 단계로 결과 제공

### 3. 악성 URL 탐지

BERT 기반 URL 분류 모델을 활용하여
URL의 악성 여부를 분석합니다.

### 4. 보안 챗봇

사용자가 탐지 결과를 이해할 수 있도록
보안 관련 질문에 답변하는 챗봇 기능을 제공합니다.

RAG 기반 검색과 LLM을 활용하여
피싱, 큐싱 및 URL 보안 관련 정보를 제공합니다.

### 5. 스캔 기록

사용자가 분석한 URL의 기록을 확인할 수 있으며
과거 탐지 결과를 확인할 수 있습니다.
